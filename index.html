Pasang Asisten Rekon

Untuk tim accounting. Tanpa ekstensi, cukup satu bookmark di Chrome. Bookmark ini selalu memuat versi terbaru, jadi tidak perlu dipasang ulang saat ada pembaruan.

1. Tampilkan bookmark bar

Tekan Cmd + Shift + B (Windows: Ctrl + Shift + B).

2. Seret tombol ini ke bookmark bar
Asisten Rekon ← tahan, lalu seret ke bookmark bar
3. Cara pakai setiap kali rekon
  1. Buka Accurate > Kas & Bank > Rekonsiliasi Bank, pilih rekening dan tanggal, klik refresh biru.
  2. Klik bookmark Asisten Rekon. Panel muncul di kanan bawah, nomor versinya tertulis di judul panel.
  3. Klik Pilih file mutasi bank (CSV/Excel dari KlikBCA Bisnis / BNIDirect), lalu isi tanggal Rekon mingguan terakhir.
  4. Kartu hijau = pasti, kuning = cek dulu, merah putus-putus = belum ada di bank.

Asisten hanya membaca layar dan file mutasi di laptop ini. Tidak ada data yang dikirim ke mana pun.
